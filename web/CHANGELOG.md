# Sarala for the web

The web app has its own version, apart from the desktop app. Each section here
becomes the notes of a `web-vX.Y.Z` release.

## 0.2.0

- Pressing Enter in a list item that has a heading or paragraph under it adds a line inside the item. That content used to turn into a code block.
- Enter on a heading or paragraph inside a list item stays in the item instead of splitting the list.
- List numbers no longer shift when you click into a list.
- Right-click Copy and Cut work on the selected text again, and Copy as Markdown and Copy as HTML copy just the selection.
- New setting under Files, "When closing unsaved": ask "Save changes?" instead of "Close without saving?". In the browser, OK saves and Cancel keeps the document open.

## 0.1.2

- Inter is the default typeface. It comes with the app, so it looks the same on every device.

## 0.1.1

Fixes for phones and touch screens.

- Tapping off the sidebar closes it. On a phone it used to cover its own button.
- Theme swatches stay on screen, and sidebar controls are large enough to tap.
- Format and Blocks explain why their rows are grey when no paragraph is selected.
- Keyboard shortcuts no longer appear on touch screens, and iPhones no longer zoom in on text fields.

## 0.1.0

The first public preview of Sarala in the browser.

- Live Markdown editing with math, diagrams, code highlighting, tables and voice typing, all running on your device.
- No account and no server. Documents stay in this browser, or in real folders on your device in Chrome and Edge.
- Works offline once loaded, and installs as an app.
- Import and export with Word, PDF, HTML and more.
- A new look of its own, with a readable page and a book typeface.
- Very long documents stay fast: tens of thousands of lines open quickly and scroll smoothly, and a single huge table or list no longer slows typing.

Not yet tried on a real iPhone, in real Safari or with a screen reader.
