# Sarala v1.1.0

## What's new

- Open multiple documents in tabs, drag tabs to reorder them, and scroll overflowing tabs alongside the command search and editor mode controls.
- Refreshed sidebar navigation, file tree, icons, and table insertion dialog.
- Improved keyboard navigation, modal focus handling, accessible labels, and focus indicators.
- More consistent Markdown rendering while editing lists, nested formatting, callouts, and embedded code.
- Equations, diagrams, metadata, footnotes, tables of contents, and supported HTML blocks keep their preview while source is edited in a floating panel.
- Expanded emoji coverage with Unicode 17 data and shortcode completion.
- Improved physics notation, equation numbering and references, and legacy sequence/flow diagram compatibility.
- Reorder table rows and columns with drag handles or keyboard controls. Structural edits refuse malformed tables that could lose extra cells.
- Structured YAML metadata, optional sandboxed HTTPS embeds, and explicitly configured image uploads.

## Validation and compatibility

12,538 automated checks pass. All 90 Markdown fixtures pass whole-document preview, editor-block preview, and exact source-preservation checks. TypeScript, ESLint, the production build, and the offline Rust check pass.

Native visual behavior, screen-reader output, and real image upload services were not verified in this pass. Math uses KaTeX with a compatibility layer; legacy diagrams use Mermaid layout. This release does not claim complete MathJax or pixel-identical Typora compatibility.

See docs/MARKDOWN-FIXES.md for implementation details and engine limitations.
