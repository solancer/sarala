# Sarala v1.1.1

## Faster

- Editing no longer re-renders the whole document. Typing, moving table rows and columns, and moving blocks now take a single frame even in long documents (previously about half a second on a 160-block document).
- Switching tabs reuses each block's rendered output and cached diagrams: about 25 ms instead of about 580 ms on the same document.
- Faster startup: syntax grammars load per language when first needed, and KaTeX and the emoji catalog load right after the window appears. The startup bundle is half its previous size.
- Theme switches re-render only diagrams, and leaving Source mode reuses unchanged blocks.
- Autosave skips rewriting a recovery copy that has not changed.

## Fixed

- Typed spaces could be saved as non-breaking spaces (U+00A0) in paragraphs, lists and headings, and a space typed after `##` could disappear.
- Typing `#` then a space in a new block put the space before the `#`.
- Mermaid diagrams could go blank after an edit elsewhere in the document.
- Nested numbered lists (for example `3.` under a bullet) jumped when clicked into.
- Bullets in loose lists sat on their own line above the item text in the preview.
- Arrow Up and Arrow Down did not leave a heading, list or quote from its first or last line.
- Escape did not close a dialog after clicking into the document behind it.
- The selection toolbar could overlap the document toolbar near the top of the page.

## Validation

All unit and browser tests pass, including a new rendering performance benchmark (`pnpm test:perf`) with a Kafka-themed stress document. Rendered output is unchanged from v1.1.0.
