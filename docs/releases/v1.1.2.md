# Sarala v1.1.2

## Editing diagrams, equations and metadata

- Clicking a diagram no longer hides it or shifts the page. The diagram stays in place and its source opens in a card attached directly below it.
- The preview follows your edits after a short pause and keeps the previous diagram on screen while the new one lays out, so it never flashes blank.
- Diagram, equation and front matter sources are syntax highlighted (Mermaid, LaTeX, YAML) in light and dark themes.

## Tables

- One tidy toolbar: layout, alignment, row and column moves, and delete. Moves that are not possible from the current cell are disabled.
- Clicking into or out of a table no longer shifts its columns or text.

## Fixed

- The update download could show 0% for the whole download. Progress now falls back to the release's file size, and otherwise shows the amount downloaded.
- Paragraphs with inline math no longer shift horizontally when clicked.
- Code in custom dark themes now uses the dark syntax colours.

## Under the hood

- Tauri 2.12 with updated plugins, Vite 8, KaTeX 0.18, js-yaml 5, TypeScript 6 and ESLint 10, plus updated Rust crates (file watching, encoding detection).
